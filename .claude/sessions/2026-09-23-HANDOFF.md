### Traps — read before repeating any of this work

Carried over from 2026-09-14, plus one new one (13).

1. **A search pattern that matches more than you meant gives a false count.** Searching for `.pad`
   also matched every `.padding(`. Look at a sample of the hits.
2. **On the Mac, the Bash tool runs zsh, not bash.** Unquoted variables do not split, and `$C:c` is
   read as a modifier. Use `${C}`, or run a script file with `bash`.
3. **The working-branch check is binding.** Whatever the §2 command lists IS the working branch.
   `archive/*` is excluded.
4. **PRs our workflows open with the automatic GitHub token have their checks held for approval
   (#2127).** A push by a person starts them. Dependabot PRs are not affected.
5. **The automatic merge does not delete the branch.** Delete it by hand, after an empty tree diff.
6. **"Closes #N" in a PR to `alpha` does not close the issue.** Close it by hand.
7. **Apple builds need `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`**, or `swiftlint`
   fails silently and `swift test` runs nothing. The Xcode licence must also be accepted.
8. **An empty review is not a clean review.** Check the error output and the size of the review file.
9. **A Node script that calls `process.exit()` can lose the end of its output into a pipe.** Write to
   a file.
10. **Before switching branches, check the target does not track `_temp/`, the session logs or the
    database dump** (#2108).
11. **Read clock times from a clock.** Do not guess them.
12. **Apple's design-guidelines page returned only its title when fetched.**
13. **New: cloud sessions cannot change the Mac.** Anything under `~` (such as `~/.claude/CLAUDE.md`)
    written in a cloud session disappears when the session ends. Computer-wide changes go through
    `tools/install-device-rules.sh`, run on the Mac.
