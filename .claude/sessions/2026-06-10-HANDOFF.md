## The #1228 blank-page bug (root cause — reusable lesson)

`/manage/duplicate-songs` rendered a **fully blank page** on alpha. Cause: the DB layer runs mysqli
under **`MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT`** (`includes/db_mysql.php`), so a failing query
**throws `mysqli_sql_exception`** — it does **not** return `false`. The page's GET detection path was
written defensively for *false-return* semantics (`if ($res) {…}`) **with no try/catch**, so any DB
error white-screened the whole page (the guards are dead code under STRICT). The exact trigger:
`$suggTableExists` probed `tblSongLinkSuggestions` but gated a read of the *different, newer*
`tblSongLinkSuggestionsDismissed` (from the #1215 batch) — which threw because that table isn't
migrated on alpha yet.

Fix (#1229): independent existence-probes per optional table; drop the `NOT EXISTS(dismissed)`
pre-filter when that table is absent; wrap the whole detection in one try/catch → actionable error
card ("apply pending migrations in Setup Database"), never blank. The page now works pre-migration
(degraded) and fully once the migration is applied.
