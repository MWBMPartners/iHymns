## How to resume in a new session

> Read `.claude/sessions/2026-11-24-HANDOFF.md` ("Current state") and `.claude/standing-directives.md`,
> then carry on with "Open work for the next session", following the standing rules.

Pattern that worked: Opus plan, then Sonnet implements in atomic commits with mutation-proven guards, then an
Opus read-only review of the risky steps, then fixes, push, pull request. The pull request title prefix
decides the version (`fix:` = build number only; `feat:` = minor). A patch release needs `Release: patch` in
the squash-merge **commit message** body.
