**Settings sync (#2178).** One list of shareable settings (`settings-sync-registry.js`), a merge that
decides setting by setting (newest change wins), one cookie `ihymns_prefs` on `.ihymns.app`. The hidden
frame "bridge" is deleted and `X-Frame-Options` has no exceptions anywhere. It is **off by default**:
an admin ticks channels under `cross_site_sync_channels` on `/manage/configuration`. Nothing but display
settings ever travels in the browser; favourites, set lists and history come from the account over `/api`.

**PHP 8.6 (#2181).** `ihymns_metaphone()` wraps the function 8.6 deprecates; a stand-in for the missing
regular-expression extension in the PDF code; `curl_close`, `imagedestroy` and `finfo_close` removed. A
guard (`test-php86-deprecations.php`) finds deprecated code from the tree. CI has an **advisory** check
called "PHP 8.6": it cannot go red until the repository variable `PHP86_ENFORCE` is set to `true`. Docs say
PHP 8.4 and 8.5 are supported and 8.6 is prepared. Local PHP in the sandbox is 8.3.

**Account rewrite, part 1 (#2182).** Phases A to C of `.claude/account-profile-rewrite-plan.md`:
safety fixes (including no longer recording who made each search), the dormant database foundation (B1,
one migration card), the manual privacy-blanking job (B2), a per-channel switch for account writes, one
shared token maker, and a profile registry with a `profile_schema` endpoint. Architecture notes:
`.claude/account-profile-architecture-review-2026-11-18.md`.
