The #1335 Service-Mode join/poll used tighter staleness windows than #1268 Live Follow (90 s join / 120 s poll vs 180 s), so a briefly-backgrounded projector tab could drop congregants or reject joins sooner. - fix(admin-login): **"Invalid form submission" lock-out when the login tab is left open** (#1386). Shared-hosting PHP session GC (`gc_maxlifetime` ≈ 24 min) reaps the *server-side* session while the browser cookie persists, so the baked CSRF token vanishes and a legitimate sign-in is rejected (incognito worked only because it's a fresh session). `login.php` now accepts a sign-in when EITHER the session token validates OR the POST is verifiably **same-origin** (`Origin`/`Referer` host matches `HTTP_HOST`) — the same robustness `validateCsrfRequest()` gives AJAX writes (rule #29), applied to the login form. Cross-origin login-CSRF is still rejected (foreign/absent `Origin`/`Referer`).
